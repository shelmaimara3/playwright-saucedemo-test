# 🎭 Playwright Automation Testing — SauceDemo

> End-to-end automation test for a demo e-commerce web application using [Playwright](https://playwright.dev/).

---

## 📋 Test Scenario

Automated flow covering the core shopping journey:

| Step | Action                                             |
| ---- | -------------------------------------------------- |
| a    | Login to homepage                                  |
| b    | Click "Add to cart" on a product                   |
| c    | Click the "Cart" icon to navigate to the Cart page |
| d    | Click the "Checkout" button                        |

## 🧪 Test Script

**File:** `saucedemo.spec.js`

```javascript
const { test, expect } = require("@playwright/test");

test("Automation Test SauceDemo", async ({ page }) => {
  // a. Login
  await page.goto("https://www.saucedemo.com/");
  await page.fill("#user-name", "standard_user");
  await page.fill("#password", "secret_sauce");
  await page.click("#login-button");

  // b. Add to cart
  await page.click("text=Add to cart", { strict: false });

  // c. Cart page
  await page.click(".shopping_cart_link");

  // d. Checkout
  await page.click("#checkout");

  // Assertion: checkout page appears
  await expect(page.locator(".title")).toHaveText("Checkout: Your Information");
});
```

## ⚙️ Setup & Installation

### Prerequisites

- Node.js >= 20
- npm

### Steps

```bash
# 1. Clone this repository
git clone https://github.com/your-username/playwright-saucedemo-test.git
cd playwright-saucedemo

# 2. Initialize project & install Playwright
npm init playwright@latest

# 3. Install dependencies
npm install
```

## ▶️ Running the Tests

### Headless mode (default)

```bash
npx playwright test
```

### UI mode (interactive)

```bash
npx playwright test --ui
```

### Generate HTML Report

```bash
npx playwright show-report
```
